# pi-setup repository instructions

`AGENTS.md` is the portable source installed as `~/.pi/agent/AGENTS.md`; it is not an additional project-policy layer. Do not shorten or replace it merely to avoid duplicate loading.

On a bootstrap machine where the global copy is not already loaded, read `AGENTS.md` in full before changing this repository and follow it as the governing repository instructions.

Keep this override repository-local: do not add it to `scripts/managed-paths.txt` or install it into `~/.pi/agent`.
